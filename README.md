# Java Texting Application
This project is a Java-based messaging application that allows users to create accounts, start private and group chats, and share image attachments. All user data, messages, and attachments are securely stored in a MySQL database, ensuring reliable and efficient communication.
## Features
- User Authentication: Users can create an account with a username and password for secure access.
- Private Messaging: Start a text chain with any registered user for one-on-one conversations.
- Group Chats: Create group chats to communicate with multiple users in one conversation.
- Image Attachments: Send and receive images within chat conversations.
- Persistent Data Storage: All user accounts, chats, and attachments are stored using MySQL, ensuring reliable data management.
## Technologies Used
- Java – Core application logic and chat functionalities.
- MySQL – Stores user credentials, messages, and attachments.
- JDBC – Connects Java applications to the MySQL database.
- JavaFX – UI components for desktop application interface.
## Usage
- Setup Database – Create a MySQL database and configure the application to connect.
- Compile & Run – Use a Java compiler to build and run the project.
- Create an Account – Register with a username and password to log in.
- Start Chatting – Create private or group chats and exchange messages.
- Send Attachments – Upload image files within conversations
